# Shafaq Electronics — GitHub Pages storefront demo

A responsive bilingual (English/Arabic) electronics storefront front-end with category filtering, product detail modals, search, and a localStorage cart.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example `shafaq-store`).
2. Upload `index.html`, `styles.css`, and `app.js` to the repository root.
3. Open Settings → Pages, choose Deploy from a branch, select `main` and `/ (root)`, then Save.
4. Wait for the Pages URL to appear.

## Important limitation
This is a **front-end demo**, not a production ecommerce backend. The cart is stored in the visitor's browser only. It does not submit orders, manage inventory, send emails, calculate shipping/tax, or process payments. GitHub Pages is not permitted for a site primarily intended to facilitate commercial transactions. For a real shop, host WooCommerce on WordPress-compatible hosting or use a supported ecommerce platform. Never collect payment/card details in this static demo.

## Before a live launch
Replace sample products/prices with real data, add official store identity/contact/policies, configure a supported backend and payment provider, and test the entire order flow.
